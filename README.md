# Photo Compress 50 to 100 KB - Free Online Image Compressor

A lightning-fast, 100% client-side web application designed to compress JPG, PNG, and WebP images precisely between **50 KB and 100 KB** directly in your browser without uploading your photos to any external server.

🔗 **Live Website:** [https://github.com/OrbitWebTools/photo-compress-50-to-100-kb](https://github.com/OrbitWebTools/photo-compress-50-to-100-kb)

---

## 🚀 Key Features

* **Strict Target Size Guarantee:** Intelligently adjusts quality and resolution to hit the exact sweet spot between 50 KB and 100 KB required by government portals, university forms, job applications, and exam registrations.
* **100% Privacy First:** All compression runs entirely client-side using HTML5 Canvas and JavaScript. Your private documents, signatures, and photos never leave your device.
* **Batch Processing:** Compress multiple images simultaneously with instant download options.
* **Zero Installation:** Runs directly in any modern browser on mobile, tablet, and desktop.
* **Built-in Cropper & Resizer:** Crop passport photos or resize dimensions on the fly.

---

## 🛠️ Tech Stack

* **Frontend:** Pure HTML5, Tailwind CSS (via CDN), Vanilla JavaScript (ES6+)
* **Image Processing:** HTML5 Canvas API, native Blob compression
* **Hosting:** GitHub Pages / Static Web Hosting
